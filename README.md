# HanoiGo – GEO Website

Website một trang về du lịch Hà Nội, phục vụ bài tập GEO.

## Có gì trong website
- Địa điểm: Hồ Hoàn Kiếm, phố cổ, Văn Miếu – Quốc Tử Giám, Hoàng thành Thăng Long, Ba Đình.
- Lịch trình Hà Nội 2 ngày 1 đêm.
- Ẩm thực: phở, bún chả, cà phê trứng, xôi, bánh cuốn.
- FAQ theo câu hỏi tự nhiên.
- WebSite Schema + FAQPage Schema JSON-LD.
- Responsive desktop/mobile.
- robots.txt + sitemap.xml.

## Chạy
Mở index.html bằng trình duyệt hoặc VS Code + Live Server.

## Trước khi nộp
1. Thay https://example.com/ bằng URL thật trong Schema, sitemap và robots.txt.
2. Deploy lên hosting có URL công khai.
3. Kiểm tra PageSpeed và Schema.
4. Test các câu hỏi FAQ trên AI Search và chụp màn hình.
